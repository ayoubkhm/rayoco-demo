Les formulaires d’accès

Les champs de connexion, d’inscription et de récupération servent à tester le parcours. Les valeurs saisies restent temporairement en mémoire dans la page et sont effacées lorsque vous validez le formulaire ou quittez la page. Elles ne sont pas envoyées à un service de comptes ni conservées dans le stockage de Rayoco.

Utilisez des noms, des adresses e-mail et des mots de passe fictifs pour ces essais.

Les données de l’atelier

Les brouillons de la Bibliothèque sont conservés dans l’onglet du navigateur jusqu’à sa fermeture, leur enregistrement ou leur abandon. Les grandes sélections de prestations gardent leurs identifiants localement pour être ouvertes dans un devis ; seules les 20 sélections les plus récentes sont conservées. Le bouton d’effacement supprime aussi ces sélections et les brouillons de cet onglet.

L’atelier démarre avec des données fictives. Les modifications que vous y apportez sont conservées localement, sous la clé rayoco-demo-v1, pour retrouver vos essais après rechargement. Elles comprennent les coordonnées d’entreprise et de clients saisies, les devis, les factures, les prestations et les coûts de chantier.

Ce stockage n’est pas une sauvegarde distante et n’est pas synchronisé entre les appareils. N’y saisissez pas de données personnelles réelles ni de dossiers clients confidentiels.

Hébergement et navigation

La consultation du site nécessite des échanges techniques avec son hébergeur, qui peut traiter des informations de connexion pour servir les pages. Les journaux, leurs durées de conservation, les éventuels transferts et les prestataires du service commercial devront être précisés avant son lancement.

La préversion est servie via GitHub Pages. Summercloud est l’hébergeur prévu pour le service commercial. Aucun outil publicitaire ou de mesure d’audience n’est ajouté dans le code de la démonstration.

Durée de conservation et effacement

Les essais dans l’atelier restent dans ce navigateur jusqu’à leur effacement, ou jusqu’à ce que le navigateur supprime les données du site. Vous pouvez les effacer depuis la page cookies et stockage.

Vos droits et le futur service

Avant l’ouverture de comptes réels, ce document devra préciser les finalités, les bases légales, les destinataires, les durées de conservation et le point de contact permettant l’exercice des droits d’accès, de rectification, d’effacement, de limitation, d’opposition et de portabilité lorsqu’ils s’appliquent.

Vous pouvez consulter les informations de la CNIL sur les droits relatifs aux données personnelles.
